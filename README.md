# token-fire

像素篝火桌面摆件：火焰大小跟随 DeepSeek 余额变化，并展示今日、昨日、本月 Token 用量、剩余 token 与消费趋势。

用 Tauri 打包，无边框、透明、置顶、不占任务栏。

## 使用

```powershell
npm run dev
npm run dev:hot
npm run build:exe
npm run build:app
```

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 生成资源、编译并启动桌面摆件 |
| `npm run dev:hot` | 热更新开发：前端改动自动刷新，Rust 改动自动重启 |
| `npm run art` | 生成篝火 SVG 和强度预览页 |
| `npm run icons` | 生成应用图标 |
| `npm run ui` | 把 `web/` 和像素引擎拼进 `ui/` |
| `npm run qa:page` | 用无头 Chrome 截图设置面板 |
| `npm run build:exe` | 只生成单文件 exe |
| `npm run build:app` | 生成 exe 和 NSIS 安装包 |

`npm run dev:hot` 会监听 `web/` 和 `src/pixel/`，改动后自动重建 `ui/` 并刷新窗口；Rust 改动由 Tauri 自动重启。

## DeepSeek 登录与用量

- 首次运行会打开 DeepSeek 官方登录页，也可以点面板里的“登录 DeepSeek”再次打开。
- 登录在官方页面内完成，应用不接管账号密码，也不把登录 Token 写进配置文件。
- 登录状态保存在应用自己的 WebView 会话中，日常同步不会显示登录窗口。
- 用量读取自 [DeepSeek 官方用量页](https://platform.deepseek.com/usage) 使用的同源接口。
- 余额读取自账户摘要；今日、昨日、本月按完整自然日范围汇总 Token，和官方用量页保持一致。
- 已登录默认每 20 秒同步一次，可在设置里改成 5 - 3600 秒；未登录时约每 8 秒检查一次登录状态，登录成功立刻更新。
- 官方数据可能延迟约 5 分钟。

设置面板包括：

| 设置 | 说明 |
| --- | --- |
| DeepSeek 账户 | 登录、打开官方页面、手动刷新 |
| Token 用量 | 当前余额，今日 / 昨日 / 本月 Token 与花费 |
| 消费趋势 | 本日 / 本周 / 本月 / 本年折线图，节点金额常显（过密时自动抽稀），悬停查看该时间点的 Token 与消费 |
| 摆件大小 | 小 112x154 / 中 152x204 / 大 200x264 |
| 火势区间 | 余额 → 火势的线性刻度，默认 1 - 1000 元；余额 ≤ 最低时最小火，≥ 满焰时满焰 |
| 提示 | 气泡显示剩余 token；以及气泡是否常显，默认只在悬停火焰时出现 |
| 同步间隔 | 已登录后的同步频率，可填 5 - 3600 秒，默认 20 秒 |
| 开机自启 | 写当前用户启动项，幂等 |
| 同步状态 | 登录、同步和错误信息 |
| 退出摆件 | 真正退出进程 |

设置存在 `%APPDATA%\token-fire\config.json`，对应字段为 `hintAlways`（提示常显）、`fireMin` / `fireMax`（火势区间，单位元）和 `syncIntervalSecs`（同步间隔秒数）。

## 火焰映射

火的大小只由余额决定，避免让一个折算出来的 token 数主导视觉；余额是官方直接给的，不会因为均价波动而跳。默认在 1 - 1000 元区间里按线性刻度铺开：

| 账户余额 | 火势 |
| --- | --- |
| 1 元及以下 | 最小火（将熄） |
| 7 元 | 区间约 0.6%，接近最小火 |
| 10 元 | 区间约 1%，接近最小火 |
| 100 元 | 区间约 10% |
| 300 元 | 区间约 30% |
| 1000 元及以上 | 满焰 |

中间按线性插值，充值和消费时火势连续过渡，不会跳档。最小火会保留一点火苗，不会完全看不见。区间可以在设置里改，余额分布偏小或偏大时都能调出有变化的火势；比如余额常在 10 - 50 元，把满焰改成 50 或 100 会更有层次。

火苗的“活跃度”跟今天烧掉的 token 走：今天没有用量时火苗比较稳，约 50 万 token 时抖动和火星密度到一半，再多趋近满值。活跃度只影响火星数量、火苗抖动幅度和拖拽热区，不改变火的大小。

火焰配色按真实木火走色温，冷端压一点紫罗兰：快灭时是紫红外焰，烧旺转橙黄，满焰时火芯发白。

摆件底部显示余额，例如 `¥14.00`。悬停火焰会浮出「剩余 ≈ 42M tok」：把今天各时段的真实花费和 tokens 先汇总再相除，得到每 token 的加权均价（不平均各时段的单价，否则小样本时段会被放大），再用 余额 ÷ 均价 得到还能买多少 token；今天没有用量时退回本周口径。每百万 token 的均价、余额和折算结果会写进气泡的 title。算不出时显示「剩余 -- tok」，不猜。可在设置里改成常显，气泡跟随火焰高度浮动。

## 交互

- 拖动摆件：只有火焰和火盆区域响应拖动，其余透明区域点击穿透到桌面。
- 右键摆件：打开设置面板。

## 目录

```text
web/                  前端源码：摆件、设置面板、火焰视图
src/pixel/            像素篝火引擎
ui/                   Tauri 使用的前端构建产物
src-tauri/src/deepseek.rs  官方登录窗口与用量同步
src-tauri/src/lib.rs       窗口、命令和应用生命周期
scripts/              构建、图标和截图工具
```

`src-tauri/src/deepseek.rs` 依赖 DeepSeek 网页当前使用的同源接口，若官方页面改版，需要同步调整该文件。
